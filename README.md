# litdave

**Luvit FFI bindings for Discord's [libdave](https://github.com/discord/libdave)**

## Features and installation

litdave covers all DAVE features as of version 1.3.0 of the library.

You need a 64-bit CPU to run litdave, as DAVE doesn't provide 32-bit libraries either.

You can install litdave by running `lit install Lort533/litdave`
